# Images de fond

Dépose ici tes images avec **exactement ces noms de fichier** — le site les
utilisera automatiquement, sans toucher au code :

| Fichier            | Page        |
|---------------------|-------------|
| `hero-home.jpg`      | Accueil     |
| `hero-lore.jpg`      | Lore        |
| `hero-races.jpg`     | Races       |
| `hero-factions.jpg`  | Factions    |
| `hero-magie.jpg`     | Magie       |

## Recommandations
- **Format** : JPG ou WebP, orientation paysage
- **Taille** : au moins 1600px de large
- **Poids** : essaie de rester sous 400-500 Ko (compresse sur https://squoosh.app si besoin — un site plus léger charge plus vite)
- **Pas besoin de retoucher la couleur toi-même** : le site applique automatiquement un fondu + une teinte sombre/verte pour que l'image s'intègre au design, quelle que soit l'image de départ

## Astuce cadrage
Comme l'image est plus visible au centre et se fond dans le noir sur les
bords (surtout à gauche, là où le texte est écrit), choisis des images où
le sujet principal est plutôt centré ou à droite.

Tant qu'un fichier n'existe pas, la page affiche simplement le fond uni —
rien ne casse.
